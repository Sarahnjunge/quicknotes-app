QUICKNOTES

A simple, responsive note-taking web app built with HTML, CSS, and JavaScript.

QuickNotes lets users create notes, organize them into categories, search through their notes, delete individual notes, and keep their notes saved in the browser using localStorage.

FEATURES

* Create notes
* Choose a category: Personal, Work, or Study
* Validate note input
* Delete individual notes 
* Search notes as you type
* Case-insensitive search
* Save notes with localStorage
* Display the current note count
* Responsive design for smaller screens

RUNNING THE PROJECT

No installation or additional dependencies are required.

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
